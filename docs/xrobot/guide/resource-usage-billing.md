## 快速了解

使用 UID 小时资源包时，平台会根据当前选择的大模型和音色，将设备会话时长折算为资源包扣减时长。模型或音色的计时系数越高，相同会话时长消耗的资源包时长越多。


扣减时长按照以下方式计算：

```text
扣减倍率 = 1 + 大模型计时系数 + 音色计时系数

扣减时长 = 设备会话时长 × 扣减倍率
```

例如，大模型计时系数为 `+0.2`，音色计时系数为 `+0.5`，扣减倍率为：

```text
1 + 0.2 + 0.5 = 1.7
```

设备会话持续 60 分钟，预计从 UID 小时资源包中扣减 102 分钟。



## 认识计时系数

| 名称 | 说明 |
| --- | --- |
| 设备会话时长 | 设备与平台建立会话连接后，到本次会话结束之间的时长 |
| 计时系数 | 大模型或音色在基础倍率上额外增加的时长系数 |
| 扣减倍率 | 基础倍率 `1` 加上大模型和音色的计时系数 |
| 扣减时长 | 根据扣减倍率折算后，从 UID 小时资源包中扣除的时长 |

计时系数是增加值，不是最终倍率。例如，音色显示“计时系数 `+0.5`”，表示在基础倍率 `1` 上增加 `0.5`，最终倍率为 `1.5`，而不是 `0.5`。

大模型和音色的计时系数会相加计算，不会相乘：

```text
大模型计时系数 +0.2
音色计时系数 +0.5

正确：1 + 0.2 + 0.5 = 1.7
错误：1 × 0.2 × 0.5
```

不同大模型和音色的计时系数可能不同，也可能为 `0`。具体数值请以智能体配置页面显示的信息为准。

## 计算示例

### 大模型和音色的计时系数都为 0

```text
大模型计时系数：0
音色计时系数：0
扣减倍率：1 + 0 + 0 = 1
```

设备会话持续 60 分钟，预计扣减 60 分钟。

### 只有音色包含计时系数

```text
大模型计时系数：0
音色计时系数：+0.5
扣减倍率：1 + 0 + 0.5 = 1.5
```

设备会话持续 60 分钟，预计扣减 90 分钟。

### 大模型和音色都包含计时系数

```text
大模型计时系数：+0.2
音色计时系数：+0.8
扣减倍率：1 + 0.2 + 0.8 = 2
```

设备会话持续 60 分钟，预计扣减 120 分钟。

::: tip 计时精度
平台按秒记录设备会话时长，并按秒折算资源包扣减时长。折算后不足 1 秒的部分不计入扣减时长。
:::

## 查看当前配置的扣减倍率

在灵矽 AI 控制台中进入智能体的角色配置页面，可以查看当前配置的计时信息：

1. 当前大模型存在额外计时系数时，模型名称旁会显示“大模型计时系数 `+x`”。
2. 当前音色存在额外计时系数时，音色名称旁会显示“音色计时系数 `+x`”。
3. 页面会根据当前大模型和音色，自动显示“预计扣减倍率”。

计时系数为 `0` 时，页面不会额外显示计时系数标签。

::: warning 配置生效时间
修改智能体的大模型或音色后，新的计时系数从后续新建立的设备会话开始生效。已经建立的会话仍按照会话建立时的配置计时。
:::


## 资源包余额和结算时间

设备会话产生的用量会持续记录。UID 小时资源包按照自然日完成正式用量聚合，因此资源包用量页面显示的余额可能存在一定延迟。

余额暂未更新不代表本次会话没有产生用量。当实时可用额度不足时，平台可能会结束当前设备会话，请及时购买或补充资源包。

## 常见问题

### 为什么计时系数是 +0.5，扣减倍率却是 1.5？

计时系数是在基础倍率 `1` 上增加的数值。计时系数 `+0.5` 表示最终倍率为：

```text
1 + 0.5 = 1.5
```

### 大模型和音色的计时系数会同时计算吗？

会。大模型和音色的计时系数会相加计算：

```text
1 + 大模型计时系数 + 音色计时系数
```

### 为什么资源包余额没有立即变化？

UID 小时资源包的正式用量按日聚合，资源包用量页面可能存在结算延迟。平台仍会持续记录会话产生的实际用量。

### 为什么实际扣减和页面显示的预计倍率不一致？

常见原因包括：

- 设备优先使用了其他可用额度，尚未进入 UID 小时资源包计时。
- 资源包用量尚未完成当日聚合。
- 智能体配置在会话建立后发生了变化，当前会话仍使用建立时的配置。
- 会话时长按秒记录，折算后不足 1 秒的部分不计入扣减时长。

最终扣减结果以资源包用量记录为准。

### 如何减少资源包时长消耗？

可以在智能体配置页面选择计时系数较低的大模型或音色，并在不需要继续对话时及时结束设备会话。不同配置提供的能力和体验可能不同，请根据实际业务需求选择。

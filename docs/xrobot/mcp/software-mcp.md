## 概述

MCP（Model Context Protocol）是新一代AI应用集成协议，基于标准 JSON-RPC 2.0 格式，实现AI平台与云端服务之间的无缝连接。通过MCP协议，大模型可以动态发现和调用外部"工具"（Tool），极大扩展AI应用的能力边界。

### MCP协议优势

- **🔌 标准化接口**：基于JSON-RPC 2.0，确保跨平台兼容性
- **🚀 动态发现**：支持工具的动态注册和发现机制
- **🔒 安全可靠**：内置身份验证和权限控制
- **📈 高性能**：轻量级协议设计，支持高并发调用
- **🛠️ 易于扩展**：模块化架构，便于添加新功能

本指南将详细介绍如何搭建云端MCP服务器，实现与灵矽AI平台的深度集成，让您的AI助手具备丰富的外部能力。

## 环境要求

云端 MCP 服务需实现标准 MCP 协议（基于 JSON-RPC 2.0），可使用任意语言/框架实现。

### 网络要求

- 服务需支持 HTTPS 访问。
- 使用 Streamable HTTP：平台通过 `POST /mcp` 发送请求。

## 接入协议说明

### HTTP Header 参数

在设备 WebSocket 会话中，平台调用智能体配置的云端 MCP 服务时，会自动携带以下 HTTP 请求头，无需经过大模型传值：

| Header 名称 | 说明 |
| --- | --- |
| `X-Linx-Device-Id` | 当前设备 ID |
| `X-Linx-Agent-Id` | 当前智能体 ID |
| `X-Linx-Session-Id` | 当前会话 ID |

MCP 服务端从请求头读取上述标识，平台不会将其自动填入工具入参（`arguments`）。

### 工具调用响应格式

**成功响应示例**：

```json
{
  "jsonrpc": "2.0",
  "id": 5,
  "result": {
    "content": [
      {
        "type": "text",
        "text": "查询成功，北京今天晴，25℃"
      }
    ],
    "isError": false
  }
}
```

**说明**：

- `content` 是数组，平台会拼接其中的 `text` 内容用于模型回复
- 需要让设备执行操作（如播放音乐、切换角色）时，返回 `structuredContent`，详见[设备操作响应格式](#设备操作响应格式)
- `isError: true` 表示工具执行失败

### 设备操作响应格式

需要让设备执行操作（播放音频、停止播放、切换角色等）时，返回 `structuredContent`：

```json
{
  "jsonrpc": "2.0",
  "id": 5,
  "result": {
    "structuredContent": {
      "code": 0,
      "funcs": [
        {
          "name": "linx_play",
          "arguments": {
            "audio_url": "https://example.com/music.mp3",
            "title": "音乐名称"
          }
        }
      ],
      "message": ""
    }
  }
}
```

`content.text` 可选，仅用于给模型或用户展示结果，不参与 `structuredContent` 的解析。

**Func 结构说明**：

| 字段 | 类型 | 说明 |
| --- | --- | --- |
| `name` | string | 系统函数名 |
| `arguments` | object | 函数参数 |

#### 内置系统函数

| 函数名 | 参数 | 说明 |
| --- | --- | --- |
| `linx_play` | `audio_url`, `title` | 播放音频 |
| `linx_stop` | 无 | 停止播放 |
| `change_role` | `role_prompt` | 切换角色 |

## 快速开始

### 1. 在灵矽AI平台注册服务

在控制台「自定义MCP」页面点击「添加自定义MCP」：

- **服务名称**：个人助手 MCP 服务
- **MCP URL**：`https://your-domain.com/mcp`
- **描述**：提供天气查询、音乐播放等个人助手功能

### 2. 接收 MCP 连接

云端 MCP 服务需实现标准 MCP 协议。平台通过 `POST /mcp` 发送请求。

### 3. 处理工具调用

当收到 `tools/call` 请求时，返回符合规范的响应格式。
